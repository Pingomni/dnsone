A fix for the Status page right after an install, an update or a restart.

## What changes

- **Fixed: "dnsone-querylog is not running" for the first minute.** The query log collector reported its state
  only a minute after it started, so until then the Status page (and `dnsone-status`) warned that it was not
  running, with or without a licence. It now reports as soon as it starts.

## Upgrading from 1.5.4

`sudo dnsone-update` (or *Settings → Overview → Software update*): no database or system changes.
