Every server registers with a free licence from the PingOmni account, DNSOne Community included.

## What changes

- **A licence key for every server.** DNSOne Community now has a free licence: sign in at
  [account.pingomni.com](https://account.pingomni.com/buy?product=dnsone&plan=Community&period=12), choose
  **DNSOne Community** (free, one server per key, up to five), and paste the key under *Settings → License*. It
  turns no Pro feature on; it registers the server. A Pro key registers it as well.
- **30 days to register.** After this update, a server without a key shows a banner on every page with the days
  left. Once they are over, the console shows only *Register this server*: the server ID, a button to get the free
  key, and a field to paste it. Signing in, *Settings → License* and the health checks stay open, and the console
  opens again as soon as a key is saved, without a restart.
- **DNS never changes because of this.** BIND, the Recursor, dnsdist, the query log, cluster sync, the jobs,
  dynamic DNS updates, metrics and joining a cluster keep running with or without a key. Scripts that use an app
  password keep working too.
- **The free key renews itself** each year in the account; the server picks the renewed key up by itself. A key that
  expired is still accepted for 30 days, with a banner asking to renew it.
- The console names a free key *DNSOne Community (registered)*. Keys from before this release keep working as they
  are.
- No database migration, and DNS keeps answering throughout the update.

## Installing

- A new server: `curl -fsSL https://raw.githubusercontent.com/Pingomni/dnsone/main/install.sh -o install.sh`, then
  `sudo bash install.sh`.
- A running server: *Settings → Software update* → **Install**, or `sudo dnsone-update`.
