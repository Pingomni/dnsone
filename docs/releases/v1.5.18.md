## What changes

- **`install.sh` no longer stops at step 3** with `mkdir: cannot create directory … Permission denied`. Since 1.5.14
  `/var/lib/dnsone` is root's, and the installer still made the folders inside it as the dnsone account, which
  cannot write there. Root now makes those folders and hands them to dnsone. An install that stopped there can
  simply be run again: download `install.sh` again and start it.
- The post-install and `dnsone-update` made the console's request folders (`update`, `firewall`, `cluster`) the
  same way, and are fixed the same way.
- Nothing changes on a server that is already running: no database migration, and DNS keeps answering throughout
  the update.

## Installing

- A new server: `curl -fsSL https://raw.githubusercontent.com/Pingomni/dnsone/main/install.sh -o install.sh`, then
  `sudo bash install.sh`.
- A running server: *Settings → Software update* → **Install**, or `sudo dnsone-update`.
