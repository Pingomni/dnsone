DNSOne 1.4.1 adds a one-command updater. Nothing else changes.

## New

- **`dnsone-update`**: `sudo dnsone-update` installs the latest release from GitHub by itself. It downloads the release, checks its checksum, backs up the database and `/opt/dnsone`, installs, migrates, restarts the DNSOne services and verifies them, and puts the old version back if anything fails. `dnsone-update --check` only says whether a newer release exists.
- Each release now comes with `dnsone-X.Y.Z.tar.gz`, the source with the console already built, so servers no longer need Node.js.

For everything in 1.4 (court-ordered blocking, customers and resellers, OpenID Connect sign-in, zone history, Safe Search, query log export, templates, dynamic DNS, DNS64, ALIAS records), see `docs/ROADMAP.md`.

## Installing

From 1.4.0, with a checkout of the repository at this release (the first time only; later updates are `sudo dnsone-update`):

```
sudo bash ops/dnsone-update
```

From 1.3.1: `sudo bash ops/dnsone-update` too. It runs `ops/dnsone-upgrade-1.4` (see `docs/RUNBOOK.md`, "From 1.3 to 1.4").
