DNSOne 1.5.2 puts the user guide in the console.

## New

- **Help** in the navigation, for every account (customers too): the whole user guide, with a contents list, search, and links straight to a section (`/help#10-protection-attacks`). It is built into the console, so it matches the installed version and works without internet.

## Upgrading

`sudo dnsone-update` (or *Settings → Overview → Software update*). Only the console changes; DNS keeps answering.
