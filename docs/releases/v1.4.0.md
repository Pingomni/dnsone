DNSOne 1.4 adds the features an ISP needs to run DNS for customers.

## New

- **Court-ordered blocking**: a separate list checked before everything else, for every customer and group; allow rules, allowlists and pauses never lift it. Entries are lifted with a reason, never deleted. Blocked names answer with a legal notice page (HTTP 451) or "does not exist"; CSV export for the regulator.
- **Customers and resellers**: custom roles, roles limited to their own zones, and the built-in *reseller* (creates zones, manages its own customers) and *customer* (edits its zones' records) roles.
- **Single sign-on with OpenID Connect**: Google, Entra ID, Okta, Authentik or any provider. Roles from a group claim, email invitations, allowed domains; local accounts keep working.
- **Zone history and rollback**: a version per publish, with what changed and who changed it.
- **Safe Search and YouTube restrictions** per client group (Google, Bing, DuckDuckGo); they stay on while ad-blocking is paused.
- **Query log export**: syslog (JSON or key=value, respecting the privacy level) and dnstap from dnsdist.
- **Zone templates** with variables, for new and existing zones.
- **Dynamic DNS**: RFC 2136 updates signed with TSIG (nsupdate, certbot), keys limited to chosen names and types, and the dyndns2 protocol routers use. Every update is checked, audited and versioned.
- **DNS64** per client group.
- **ALIAS records**, also at the zone apex, re-resolved and republished when the target's addresses change.
- An **Update** link in the console sidebar, to this page.

## Upgrading from 1.3.1

Build the frontend (`npm ci && npm run build` in `frontend/`), then on each server, the primary first:

```
sudo bash ops/dnsone-upgrade-1.4 /path/to/dnsone-src
```

The database changes are additive. DNS pauses for a second or two while dnsdist restarts. If `/etc/dnsdist/dnsdist.conf` has local edits, the script stops before changing anything and shows them; merge them and rerun with `--keep-dnsdist`. Rollback: `sudo bash ops/dnsone-upgrade-1.4 --rollback /var/backups/dnsone/pre-1.4-….tar.gz`.

Details: `docs/RUNBOOK.md`, "From 1.3 to 1.4" and "ISP features (1.4)".
