The user guide moves to pingomni.com.

## What changes

- **Help opens the guide on pingomni.com** ([pingomni.com/docs/dnsone](https://pingomni.com/docs/dnsone/)), in a new tab.
  The guide there is much longer: every page and field with examples, installing and updating, and every server
  command. It describes the latest release.
- The console no longer carries its own copy of the guide. An old bookmark of `/help` opens the new page.
- Nothing else changes: no database migration, and DNS keeps answering throughout the update.

## Installing

- *Settings → Software update* → **Install**, or `sudo dnsone-update`.
