DNSOne is now free and open source (AGPL-3.0), with DNSOne Pro in the same release: its features turn on with a
licence key (Settings → License).

## What changes

- **Without a licence, DNSOne runs as DNSOne Community**: hosted zones on BIND with DNSSEC, templates, history,
  dynamic DNS; the customer resolver with rate limits, DoT/DoH, serve-stale and ECS; ad-blocking with client
  groups, Safe Search and DNS64; the query log, alerts, metrics, backups and updates.
- **With a DNSOne Pro licence**: attack protection, the firewall, zone transfers to customers' secondaries, quotas
  and resellers, court-ordered blocking, single sign-on, query log export and cluster management, as before.
- **An expired licence never changes DNS answers**: the Pro features keep running as they were (court orders stay
  blocked, transfers and protection keep applying) and can be changed again once the licence is renewed.
- The Pro files are under the Elastic License 2.0 (LICENSE-PRO); everything else under the AGPL-3.0 (LICENSE).

## Upgrading from 1.5.2

**Servers that use Pro features: install your licence first.** In 1.5.2, open *Settings* and note what you use;
after the update, paste the licence key under *Settings → License*. Until then the Pro features are off: for
example court-ordered blocking stops, and zone transfers to customers' secondaries are refused. Ask PingOmni for
a key before updating: hello@pingomni.com.

`sudo dnsone-update` (or *Settings → Overview → Software update*) installs it like any patch release: no
database or system changes.
