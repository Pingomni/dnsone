A one-command installer, and a fix for the query log without a licence.

## What changes

- **install.sh**: installs DNSOne on a fresh Ubuntu 24.04 LTS server with one command
  (`curl -fsSL https://raw.githubusercontent.com/Pingomni/dnsone/main/install.sh -o install.sh && sudo bash install.sh`).
  It asks for four values, each with a suggestion from the server, does every step of the runbook's Phase 1 and
  prints the console URL with the first administrator's password. `--help` lists the options. The console's
  timezone is the server's own (`--timezone` for another), and every value in `/root/dnsone-secrets.env` is quoted,
  so an answer with a space no longer stops the install at step 4.
- **Fixed: the query log without a DNSOne Pro licence.** In 1.5.3 the collector stopped reporting its state on
  servers without the query log export licence, so the Status page showed "dnsone-querylog is not running".

## Upgrading from 1.5.3

`sudo dnsone-update` (or *Settings → Overview → Software update*): no database or system changes.
