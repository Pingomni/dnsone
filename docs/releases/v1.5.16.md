DNSOne's new mark, the Tree, readable in the sidebar.

## What changes

- **The mark reads in the sidebar.** 1.5.15 drew the new mark in the page's text colour, which in the light theme is
  dark on the dark sidebar, so only its teal dot showed. In the sidebar it now takes the sidebar's white ink, like
  the name beside it.
- From 1.5.15: **a new mark**, the Tree, from the PingOmni family (with PingOmni Monitor's Pulse and RadiusOne's Key),
  and a new favicon.
- Nothing else changes: no database migration, and DNS keeps answering throughout the update.

## Installing

- *Settings → Software update* → **Install**, or `sudo dnsone-update`.
