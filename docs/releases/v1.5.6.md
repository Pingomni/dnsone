A fix for the installer.

## What changes

- **Fixed: the installer could stop at step 8 with "Duplicate entry 'node.…' for key 'settings.PRIMARY'".** Step 8
  starts the sync timer, which syncs at once, and then syncs itself; when both wrote the server's first heartbeat at
  the same moment, one failed and the installer stopped before nginx, the firewall and the verification. A heartbeat
  is now a single statement that creates or updates the record. Hit by it? Run `sudo bash install.sh` again: it
  keeps the secrets, the database and the administrator, and finishes.

## Upgrading from 1.5.5

`sudo dnsone-update` (or *Settings → Overview → Software update*): no database or system changes.
