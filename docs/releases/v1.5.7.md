A fix for the Firewall page.

## What changes

- **Fixed: Settings → Firewall always said "changes not applied" on 1.5.6.** The rules now carry the cluster
  primary's address (1.5.6), which the page did not compare, so it saw a difference where there was none.
  The rules themselves were applied correctly.

## Upgrading from 1.5.6

`sudo dnsone-update` (or *Settings → Overview → Software update*): no database or system changes.
