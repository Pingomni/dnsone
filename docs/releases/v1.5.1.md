DNSOne 1.5.1 adds a user guide and shows quotas on the profile page.

## New

- **User guide** (`docs/USER-GUIDE.md`): every feature of the console, for operators, administrators, resellers and customers.
- **My profile** shows the account's limits (zones, records per zone, API requests a minute) when it has quotas.

## Upgrading

`sudo dnsone-update` (or *Settings → Overview → Software update*). Only the console changes; DNS keeps answering.
