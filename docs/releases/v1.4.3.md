DNSOne 1.4.3 fixes the audit log's action filter.

## Fixed

- **Audit log**: filtering on an action with an underscore (`settings.update_requested`, `auth.login_failed`, …) found nothing, because the filter dropped `_` from the search. `_` and `%` are now matched as themselves, as in every other search.

## Installing

Settings → Overview → Software update, or `sudo dnsone-update`. From 1.4.0 or 1.4.1, run `sudo dnsone-update` once; it also sets up installing from the console (new in 1.4.2).
