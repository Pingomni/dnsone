Blocklists that block whole top-level domains.

## What changes

- **Fixed: AdBlock lists that block a whole TLD lost those entries.** A line like `||casino^` blocks everything
  under `.casino`; DNSOne kept only names with a dot in them, so HaGeZi's *Most Abused TLDs* list gave 10
  domains instead of 127. Such lines now block the TLD and, with *block subdomains* on, every name under it.
  A lone word in a hosts file or a plain list is still ignored (there it is more often junk than a TLD).
  Lists refresh every 6 hours; click *Refresh* on a list to read it again now.
- **Fixed: Check a domain** now sees a TLD a list blocks (`shop.casino` is blocked by `*.casino`).

## Upgrading from 1.5.9

`sudo dnsone-update` (or *Settings → Overview → Software update*): no database or system changes.
