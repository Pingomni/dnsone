Your server shows up in your PingOmni account.

## What changes

- **New: licence registration.** With a Pro key installed, the server now registers with your PingOmni account
  (account.pingomni.com) and checks in twice a day. The licence's page there shows the server it runs on and its
  last check-in. *Settings → License* shows the registration as **PingOmni account**: registered, waiting, or why
  not (for example, the licence already runs on another server).
- **New: renewed keys arrive by themselves.** After you renew a licence, the next check-in installs the new key;
  no copying and pasting.
- Report only: the Pro features never depend on the portal. If it cannot be reached, nothing changes and the server
  tries again an hour later. The server sends the key, a hash of `/etc/machine-id` and its host name; set
  `DNSONE_ACCOUNT_URL=` (empty) in `/etc/dnsone/dnsone.env` to turn registration off.
- Removing the licence frees the server in your account.
- `dnsone-ctl license check-in` registers or checks in now.

## Upgrading from 1.5.10

`sudo dnsone-update` (or *Settings → Overview → Software update*): no database or system changes. The server
registers within a minute of the update.
