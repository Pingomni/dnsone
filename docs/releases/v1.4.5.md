DNSOne 1.4.5 tightens zone transfers.

## Fixed

- **Zone transfers through port 53 are refused.** dnsdist now refuses every AXFR/IXFR. Cluster secondaries are not affected: they transfer from BIND on port 5301 directly.

## Upgrading

`sudo dnsone-update` (or *Settings → Overview → Software update*). The post-install step adds the rule to `/etc/dnsdist/dnsdist.conf` (kept as `dnsdist.conf.pre-1.4.5`), checks it with `dnsdist --check-config` and restarts dnsdist: DNS pauses for a second or two. If the check fails, the previous file is put back and the update says so.

Check from outside the customer networks: `dig @YOUR-DNS-SERVER example.com AXFR` answers "Transfer failed."
