Licences per server, or per cluster, and joining a cluster without a licence.

## What changes

- **Settings → License shows this server's ID** (e.g. `DNS1-LF3W-KK7M-LQ5Z-IFGF`), with a Copy button. A DNSOne
  Pro licence is issued for that ID, so it works on that server only. **A cluster needs one licence**: issued for
  any one of its servers, saying how many servers it covers, and pasted on any of them, so all the cluster's
  servers share it. The page shows *Servers: 2 of 2*. With more servers running than the licence covers, it warns;
  DNS never changes because of a licence.
- **A server without a licence can join a cluster**, and then runs with the cluster's licence: Settings → Cluster
  shows it *Join a cluster* (and *Leave the cluster* once it is a replica), nothing else. Joining needs a place in
  the cluster's licence: with all its servers in use, joining (and *Add server* on the primary) says so and asks
  for a licence for one more. **Creating a cluster** (adding servers) **still needs DNSOne Pro.**
- Settings → Cluster shows each node's server ID.
- Licences issued before 1.5.12 name no server, and keep working as they are.

## Upgrading from 1.5.11

`sudo dnsone-update` (or *Settings → Overview → Software update*): no database or system changes.
