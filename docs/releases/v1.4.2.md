DNSOne 1.4.2 moves updating into the console, as in RadiusOne.

## New

- **Settings → Overview → Software update**: shows the installed version and the latest release, with its notes. **Install** updates the server from the console: it downloads the release, checks it, backs up, installs, verifies, and puts the old version back if anything fails. The log is shown as it runs. **Check for updates** asks GitHub again (it is otherwise asked at most once an hour). Administrators only.
- The sidebar's Update link is gone; the update lives in Settings now.
- The console never runs the update itself. It leaves a request that `dnsone-update.path` (root) sees, and `dnsone-update --console` reports its progress back to the console. `DNSONE_UPDATE_CHECK=0` in `/etc/dnsone/dnsone.env` stops the console from contacting GitHub.

## Installing

From 1.4.0 or 1.4.1, run this once on the server (it also sets up installing from the console):

```
sudo bash ops/dnsone-update        # from a checkout of this release; or sudo dnsone-update on 1.4.1
```

After that, updates are installed from Settings → Overview, or with `sudo dnsone-update`.
